# Вечерний прогон — чек-лист

С 19.09 каждый вечер один человек проходит этот список на собранной версии и пишет в чат одну строку: «прошел» или «сломалось на шаге N: что увидел». Прогон занимает 10–15 минут. Нужны два аккаунта MAX (свой и, например, второй телефон или аккаунт тиммейта) — один учитель, один ученик. Шаги, которые еще не реализованы, пропускаем и пишем «N — нет».

Как читать: слева что делаем, справа что должно случиться. Если случилось не то — это и есть «сломалось на шаге N».

## А. Учитель

1. Отправить `/start` с аккаунта учителя. — Приветствие и две кнопки: [Я ученик] [Я учитель].
2. Нажать [Я учитель]. — Просит код учителя.
3. Ввести неверный код (например `123`). — «Не тот код», предлагает [Я ученик]. Класс не создан.
4. Ввести верный код из `.env` (`TEACHER_CODE`). — Спрашивает, какой класс, кнопки [7]…[11].
5. Нажать [8]. — Спрашивает, сколько учеников.
6. Ввести `abc`. — Просит число, не падает.
7. Ввести `3`. — Показывает код класса из 4 символов (без 0/O/1/I) и «Номера: 1–3». Код запомнить — он нужен в блоке Б.
8. Отправить `/report`. — Класс, 8 класс, 3 ученика; привязаны: никого; свободны: 1–3.
9. Отправить `/class`. — Снова спрашивает класс, можно создать второй. Создать и проверить, что `/report` предлагает выбор из двух.

## Б. Ученик

10. С аккаунта ученика `/start`. — Приветствие, [Я ученик] [Я учитель].
11. [Я ученик]. — «У тебя есть код класса?» [Есть код] [Нет, сам по себе].
12. [Есть код], ввести несуществующий код `ZZZZ`. — «Такого кода нет», предлагает [Нет кода]. Не падает.
13. Ввести код из шага 7. — Просит номер в классе.
14. Ввести `7`. — «Номер вне диапазона» или похожее: в классе номера 1–3.
15. Ввести `2`. — Просит подтвердить: «Ты — номер 2 в классе XXXX?» [Да] [Нет, другой].
16. [Да]. — Согласие на хранение ответов без имени и кнопка [Понятно, начнем] (или сразу первые карточки).
17. Отправить `/start` еще раз. — «Ты ученик класса XXXX, номер 2» и [Продолжить] [Начать заново]. Второй регистрации нет.
18. С аккаунта учителя `/report`. — Привязан: 2. Свободны: 1, 3.

## В. Задание дня

19. С аккаунта ученика `/task`. — «Задание дня. Выбери одно:» и три кнопки с заголовками. Заголовки не выдают тип (нет слов «логика», «техника»).
20. Написать текстом `привет`, не нажимая кнопку. — «Выбери карточку кнопкой выше».
21. Нажать первую карточку. — Текст задания и четыре кнопки [А] [Б] [В] [Г].
22. Написать текстом `А`. — «Выбери вариант кнопкой ниже».
23. Нажать любой вариант. — Ответ бота из `feedback` именно под этот вариант: у проверяемого — «Верно…» или «Не совсем… Правильный — X», у непроверяемого — «Записал…». Затем «+1 к «…». Всего заданий: 1».
24. Нажать кнопку варианта из уже закрытого задания (старое сообщение). — «Это задание уже закрыто. Текущее — выше». Второе событие не пишется.
25. `/task` еще два раза, решить оба. — Оба раза три новые карточки, ни одна не повторяет уже решенные.
26. `/task` четвертый раз за день. — «На сегодня хватит. Завтра в 16:00».
27. `/profile` после 3 заданий. — «Пока рано: сделано 3 из 5».

## Г. Профиль (когда решено 5+)

28. `/profile` после 5 заданий (на следующий день или с временно снятым лимитом в `.env`). — Пять строк с полосками и числами, фраза-резюме, до 3 направлений или «Направления покажу, когда профиль станет четче».
29. С аккаунта учителя `/report`. — Активных: 1, средний профиль класса из пяти чисел.

## Д. Служебные

30. Ученик: `/help`. — Список команд, ничего лишнего.
31. Ученик: любой текст в покое, например `ыыы`. — «Не понял. Команды: /task /profile /help». Бот не молчит.
32. Ученик: `/number`, ввести `3`. — Номер сменился; `/report` у учителя: привязан 3, свободны 1, 2.
33. Учитель: `/free 3`. — Ученик получает «Учитель освободил твой номер. Введи свой: /number». В `/report` номер 3 свободен.
34. Ученик: `/reset`. — Просит подтверждение; после [Да] — снова выбор роли. `/report` у учителя: свободны все.
35. Учитель: `/reset`. — Подтверждение; роль сброшена, классы остались (проверить после повторного входа как учитель).

## Е. Инфраструктура (Карим, раз в день)

36. `docker compose up` на чистой машине по README. — Контейнер стартует, бот отвечает на `/start`.
37. Перезапуск контейнера. — Данные на месте: ученик из блока Б по-прежнему привязан.
38. `pytest` в CI на последнем коммите main. — Зеленый.

## Как писать в чат

Одна строка. Примеры:
«Прогон 19.09: прошел до 27, дальше не дошел — профиль еще не собран».
«Прогон 19.09: сломалось на 14 — бот принял номер 7 при классе на 3 человека».
