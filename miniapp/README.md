# Мини-приложение: отчет учителя

Одна страница без сборки: `index.html` (обычный JS, стили внутри) читает `report.json` и рисует отчет по классу. Открывается двойным кликом по файлу. Потом тот же JSON будет отдавать сервер, страница заменит файл на запрос.

`report.json` — пример на 12 учеников, сгенерирован из `seed.py` через `scoring.py`, поля:

- `mock`, `note` — модельные данные; `note` показывать на странице внизу.
- `class_code`, `grade`, `size` — класс.
- `bound`, `free` — привязанные и свободные номера.
- `active_days`, `active` — окно активности и сколько активных (есть ответ за последние 14 дней).
- `passed_10` — прошли 10 и больше заданий; `not_started` — привязаны, но ни одного ответа; `distinct` — с выраженным профилем.
- `average_profile` — средний профиль класса по осям H T S I N (0..1), считается по ученикам с 5+ заданиями.
- `axis_names` — как называть оси по-русски.
- `students[]` — по каждому: `number`, `solved`, `scores` по осям, `leading` (одна-две ведущие оси), `distinct`, `active`, `last_answered`.

Что на странице: шапка (класс, код), четыре цифры (привязано, активных, прошли 10+, не начинали), средний профиль пятью полосками, таблица по ученикам (номер, заданий, ведущие оси по-русски, выраженный или нет, активен или нет), внизу `note`.
